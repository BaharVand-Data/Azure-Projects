## Overview

This project was completed as part of the **Microsoft Azure Data Fundamentals (DP-900)** training course and demonstrates foundational knowledge of cloud computing, modern data concepts, and Azure data services. The project explored the end-to-end data lifecycle, including data storage, ingestion, processing, analysis, and reporting across both relational and non-relational environments within the Microsoft Azure ecosystem.

The work focused on understanding how organisations can manage and analyze data using various Azure services while applying industry best practices for scalability, security, and performance.
